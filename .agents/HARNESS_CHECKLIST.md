# HARNESS_CHECKLIST.md

> 기능을 프로덕션에 배포하거나 다른 사람에게 인계하기 전에 실행합니다.  
> 실패 항목은 블로커입니다. 건너뛴 항목은 서면 사유가 필요합니다.

---

## 에이전트 지침 (AGENTS.md)

- [ ] 프로젝트 개요가 현재 상태를 정확히 반영한다
- [ ] 레포지토리 구조가 실제 디렉토리 레이아웃과 일치한다
- [ ] 도구 권한이 명시적으로 정의되어 있다 (허용/확인 후 진행/금지)
- [ ] 검증 게이트의 커맨드가 실제로 동작한다
- [ ] 중의적으로 해석될 수 있는 지침이 없다

---

## 코드 품질

- [ ] `cd backend && go build ./...` 에러 없음
- [ ] `cd backend && go vet ./...` 경고 없음
- [ ] 변경된 도메인의 테스트가 통과한다
- [ ] `import` 순서가 컨벤션을 따른다 (표준 → 서드파티 → 내부)
- [ ] 핸들러가 비즈니스 로직을 직접 포함하지 않는다 (서비스/DB 레이어를 통해 호출)
- [ ] 에러 응답이 `gin.H{"error": "..."}` 형식이다

---

## 도메인 레이어 규칙

- [ ] `api/handlers.go`: HTTP 입력 검증 + 응답만, 쿼리 없음
- [ ] `database/`: DB 접근만, 비즈니스 로직 없음
- [ ] `model(s)/`: 타입 정의만
- [ ] `service/` (있는 경우): 비즈니스 로직만

---

## 보안 체크

- [ ] API 키, 패스워드, 시크릿이 코드에 하드코딩되어 있지 않다
- [ ] API 키가 로그에 출력되지 않는다
- [ ] `.env` 파일이 `.gitignore`에 포함되어 있다
- [ ] Admin 엔드포인트에 민감한 쓰기 동작이 추가되었다면 인증 상태를 인지하고 있다
- [ ] 사용자 입력이 DB 쿼리에 직접 포함되지 않는다 (SQL 인젝션 방지)
- [ ] 외부 크롤러/API 응답이 신뢰 없이 직접 실행되지 않는다

---

## 데이터베이스

- [ ] DuckDB에 쓰기 작업이 없다 (읽기 전용)
- [ ] Candle 쿼리에 Hive 파티션 필터(`market=`, `year=`, `month=`)가 적용된다
- [ ] SQLite 스키마 변경이 있다면 마이그레이션 코드가 포함되어 있다
- [ ] Meilisearch 인덱스 설정 변경이 있다면 문서화되어 있다

---

## API & 문서

- [ ] 새 엔드포인트가 `API.md` 또는 `docs/`에 문서화되어 있다
- [ ] 응답 형식이 같은 도메인의 기존 엔드포인트와 일치한다
- [ ] 에러 케이스가 적절한 HTTP 상태 코드를 반환한다 (400/404/500)

---

## 프론트엔드 (프론트 변경이 있을 경우)

- [ ] `cd frontend && npm run build` 성공
- [ ] 새 컴포넌트가 `lib/components/`에 있고 PascalCase 파일명이다
- [ ] API 호출이 하드코딩된 URL 없이 환경 변수 또는 상대 경로를 사용한다
- [ ] Tailwind/DaisyUI 컴포넌트를 사용하며 인라인 스타일이 최소화되어 있다

---

## 컨텍스트 전달

- [ ] 장기 상태(계획, 결정, 진행 상황)가 코드 주석이 아닌 파일에 기록되어 있다
- [ ] `IMPLEMENT.md`에 주요 결정과 이탈 사항이 기록되어 있다
- [ ] 민감 정보가 에이전트 접근 가능한 컨텍스트에 포함되어 있지 않다

---

## 인프라 (배포 변경이 있을 경우)

- [ ] `docker-compose.yml` 변경이 있다면 로컬에서 `docker-compose up` 테스트 완료
- [ ] 새 환경 변수가 `.env.example`에 플레이스홀더로 추가되어 있다
- [ ] 포트 충돌이 없다 (기존 포트: 8080 서버, 7700 Meilisearch, 5173 Vite dev)

## 하네스 컴포넌트 제거 기준

> 모든 하네스 컴포넌트는 모델이 아직 할 수 없기 때문에 존재합니다. 불필요해지는 조건을 문서화하십시오.

| 컴포넌트 | 존재 이유 | 제거 가능 시점 |
|---------|---------|-------------|
| 도메인 레이어 강제 | 핸들러가 DB를 직접 호출할 경우 유지보수 불가 | 레이어 인식 도구가 자동으로 검사할 때 |
| Admin 인증 없음 경고 | JWT 미구현 상태 인지 필요 | Admin 인증 구현 후 |
| DuckDB 읽기 전용 경고 | 쓰기 시 파일 잠금 오류 | 읽기/쓰기 분리 구조 구현 후 |
| Kiwoom Windows 전용 경고 | Linux CI에서 빌드 실패 방지 | 빌드 태그 자동화 또는 REST API만 사용 시 |
